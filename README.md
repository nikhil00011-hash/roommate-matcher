# Roommate Matcher

**Live demo:** [Open Roommate Matcher](https://roommate-matcher-production.up.railway.app/)

A college mini project for finding compatible roommates based on lifestyle, habits, and preferences.

## Features

- Create an account and build a roommate profile
- Browse compatible roommates
- Send and respond to connection requests

## Tech stack

Java 17, Jakarta Servlets/JSP, embedded Tomcat, MySQL, Maven, and Docker.

## Source

The complete project source is available in [Roommate-Matcher.zip](./Roommate-Matcher.zip). The root Dockerfile builds and runs the uploaded source archive.
